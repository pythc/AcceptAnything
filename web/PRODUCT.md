# 验收工作台

本地自托管的验收记录与证据工作台。面向需要理解执行范围、定位问题并核对原始证据的开发者与验收人员。

## 核心任务

- 通过本地路径或远程仓库接入目标，识别、确认并冻结源码与验收范围。
- 查看真实流水线、单项检查、执行状态、覆盖缺口与门禁判定。
- 阅读缺陷的预期、实际、影响、优先级建议和复核记录。
- 从检查或发现进入关联原件，核对来源、摘要、片段与下载。
- 浏览代码仓库、历史验收、接入与引擎能力。

## 不变约束

三个主标签为验收流程、缺陷详情、证据溯源。所有数字、版本、时长、模型信息和结论来自既有 API；缺失数据不能补造。执行完成不等于验收通过，未完成的必验范围必须保留。原始报告和冻结预期不因 UI 重构而改写。复核操作维持现有服务端校验。

## 当前设计决定

2026-10-31 用户选定浅色、简约、单列工作台，并授权按选定图重构现有前端。默认展示需要处理的检查，逐项行内展开；已完成检查折叠，仍可查看标准与原件。流水线保持一行横向滚动。动效只辅助展开、切换和状态反馈。

## 技术与交付边界

React / TypeScript / Vite，复用 Phosphor 图标与现有 API。此轮交付为本地 UI 重构及预览；不代表新一轮目标仓库验收、模型验证或生产部署完成。详细历史约束见 AGENTS.md。
