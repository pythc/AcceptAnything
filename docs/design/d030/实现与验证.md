# D030 · 统一验收三页面：实现与验证

## 本批实现

依据用户批准的D029，统一石墨灰侧栏、仓库目标信息、页签与柔和紫色主操作。

1. 验收流程：单行可滚动流水线，真实阶段状态、耗时、复用状态；检查整行可点，选择检查显示真实结论、位置和缺陷入口；完整命令与校验折叠。
2. 缺陷详情：默认待处理60，按已确认/待复核/用例问题/非缺陷过滤与搜索。P级保留建议标识，展示发生了什么、影响、原始诊断、确认依据、复核表单和历史。
3. 证据溯源：按步骤组织真实文件，保留范围切换与搜索；展示源码→执行检查→报告→发现的关联、真实命令、退出码与耗时；JUnit可读解读、原始XML、复制、下载、文件校验与轨迹查看保留。
