## 边界

这次实现的是按技术栈与执行协议自动组合的通用验收流程，不代表所有任意仓库都已可完整业务验收。当前执行 Python、Node、Go，支持数据参数的函数、CLI、单服务 HTTP 和浏览器文本断言；复杂对象构造、跨调用对象复用、多服务事务、其他语言运行协议仍有缺口。原生测试可能具有第三方、可选依赖与版本兼容条件，缺少这些条件时保留真实状态。

源文档定位与原件校验能证明引用出处及未改预期，不能自动证明模型对需求的全部语义解释正确。模型标准/输入/预期/实际结果均可展开复核。不将未覆盖需求、缺部署条件或无指标的性能/恢复工作声称为通过。

当前按持久队列依次分项执行，依赖图实现局部失败隔离；没有宣称所有分支同时并行。
