# D037 · 通用发现、环境、生成与分项执行

## 定位与协议

仓库名称、URL、业务常量不参与执行器选择。不新增项目专用配方。默认本地/远程接入进入通用协议；显式选择旧配置的兼容入口仅供历史使用。

技术栈、运行组件、执行协议（module/CLI/HTTP/browser）、前置依赖、独立标准和证据构成计划。公共接口有固定字段：运行组件/源码路径/公开导出名/参数与类型/返回类型/重导出关系；输入输出预期只能来自独立文档。Python复用标准库AST，JS/TS复用Babel，命令行、原生测试、扫描、报告和门禁复用既有成熟执行器。

## 入口与发现

POST /api/acceptance/plan：不要求指定函数、手写启动脚本或逐份勾选文档。静态发现项目声明、多模块、公开导出/签名与重导出、服务框架和声明的启动脚本；扫描全索引，依据文档中的符号相关性选择模型上下文，完整索引归档。

README、需求、契约、规格与接口文档自动分类、按原文字符片段分批，分片拼接可还原全文；不再把4文件或前12k字符限制交给用户。单次最多12批与10组件为明确资源预算，超过部分记录未覆盖，不声称全文/全仓覆盖。

返回auto-*、kind=universal、运行组件/能力/文档批次/初始缺口/计划摘要。ready表示可以开始收集真实结果，不表示模型用例已经通过，也不表示最终可放行。POST /api/acceptance/runs仍使用plan_id+digest进入持久执行队列与统一详情页。

## 通用执行

每个组件有独立安装/构建/原生测试/业务分支；扫描与生成按独立任务处理。安装或构建失败只影响相关依赖分支，其他组件与扫描继续，清理始终尝试。模型批次、标准和用例独立校验，错误引文、未知入口、缺契约单列；正确的其他用例继续执行。

Python使用完整隔离venv和项目声明依赖，JS按项目声明安装/构建/测试，Go按模块下载/构建与gotestsum。生成器只输出受约束的数据，不输出可在宿主运行的任意脚本。公开Python导入名/JS包名可唯一映射到静态证明的导出文件，定位投影保留原始响应且不改输入或预期。

服务就绪与业务验证分离：单一Flask/FastAPI声明或npm start生成通用服务任务；HTTP与浏览器在固定服务协议上运行，响应状态/JSON Pointer或页面文本来自需求断言。多服务拓扑不明确时记录缺口，模块检查继续。未配置的性能SLO、恢复标准和外部真实服务不推测通过。

环境使用固定镜像ID、只读原始源码、临时工作副本与独立容器/卷。安装阶段有网络，验证阶段断开安装网络；服务在内部网络，通过固定relay仅绑定本机随机端口。没有宿主凭据、Docker socket或宿主项目写挂载。宿主独立断言不随目标容器共享；target只接收调用信息。容器/卷/网络按本次run标记清理，不影响其他工作负载。

## 判定与证据

execution_complete表示所有计划任务均已处理到终态；complete表示声明范围的覆盖与执行均完整。局部错误、未验证需求、未处理文档和缺失用例不阻止其他检查，但向OPA传入recipe_complete=false，不能放行。业务断言失败、工具报告发现、执行器异常与覆盖缺口分别保留，不通过改源码/原测试/模型预期获得通过。

冻结源码、计划、依赖图、工具链、完整发现索引、输入文档片段、模型请求/响应/草稿/引用位置、逐用例输入/预期/实际、JUnit、原生命令输出、环境与回收记录。归档重验模型原件投影、源文档与发现绑定、逐用例身份和驱动文件；历史记录仍按其原始范围只读展示。

## 验证策略

平台测试覆盖：超过100个辅助文件不会挤掉文档相关公开入口、AST不执行目标代码、默认导出/类型/重导出、24份文档完整分片、一条错误引用/未知调用仍保留其他有效用例、包名定位不改预期、嵌套布尔与数值严格区分、一个组件安装失败不会阻止其他分支或扫描、生成执行器不能绕过准备确认、无独立依据仍可扫描但不能放行。

真实验证对象由三个首次接入的公开仓库组成：Python jmespath.py、Node escape-string-regexp、Go qsreplace。验证脚本仅提供仓库地址，不提供项目业务答案或专用命令；原始提交和每次尝试保留。实测结果完成后单独追加，失败不删除。
