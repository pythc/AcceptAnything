# D040 代码自审

由实现代理自行审阅，不是用户审批或独立安全审计。

- 读取范围：文档检索只在既有冻结清单中匹配，不联网、不执行仓库配置。第三方域名不映射；模糊路径或重复锚点不猜测。显式 toctree 循环去重，长片段分割保留末尾，原文区间保持可追溯。
- 作用范围：支持文档只能补充主文档的业务范围，模型仍可能遗漏或误解，因此记录上下文角色和原件；不声称整个文档目录已验收。批次总量不静默截断，单次模型请求仍受接口输入预算约束。
- 环境隔离：子组件在独立容器副本安装，父级安装仅为 Node 模块解析准备，不修改冻结源/原仓库；Python 本地依赖绑定同版源码。fixtures/testdata/vendor 不自动成为运行组件。服务工厂只静态识别，没有宿主导入。
- 判定：候选结果集合保持严格类型比较，错误候选失败、空集合拒绝、旧协议不能使用新比较。模型对 gap 的分类注明来源，未知执行异常不硬归因为产品缺陷。原生跳过项展开留证。
- 兼容：旧三轮完整记录仍通过原响应重新投影和证据完整性校验；未回写旧结果。模型的原响应/引用/输入/预期仍冻结，分类显示不改变放行逻辑。
- 回归：621 项后端通过（1 条既有 Starlette 弃用提示）；37 项前端通过，TypeScript 与构建通过。后续实仓结果单独记录，不能用平台回归冒充验收对象通过。

### r5 异步包装器的字段观察

Fastify r4 为 12 条业务通过、1 条异常。异常用例的 inject 返回 Chain，包装器上 body 是配置方法；模型用 get 读取 body，驱动误把方法当实际响应字段，甚至尚未发起真实请求。这是通用的 thenable 结果观察缺口，不是文本解析已失败。
