## 尚不能自动成立的范围

1. 文档里有 worker 命令，但没有可执行的多服务图：属于平台编排及依赖环境缺口，不能说完全缺少依据，更不能用同步任务函数替代 broker/worker/Web 工作流。
2. README 仅宣称 Ajax 效果，却没有该应用的输入、路径或页面输出：仍需独立依据；实现、模板和测试可以帮助接线，不能提供正确答案。
3. 浏览器表单提交、任务轮询和多进程状态隔离：当前单页面文本浏览器协议不足，进程内客户端通过只能证明相应进程内流程。
4. 特定硬件的吞吐数字和 SansIO 全称架构约束：需要明确可比环境、范围和专门验证协议，有限样本或扫描器零命中不能作为证明。
5. 模型设计存在随机性，批次间可能有重叠意见或局部矛盾。原响应、冻结用例、实测结果分别保存；统计不把不同范围的缺口数量变化当成覆盖率改善。
