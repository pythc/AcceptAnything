# 开源复用与通用验收实施清单

本批承接 D024 的差距分析。目标是复用成熟开源执行、管理和调度能力，补齐验收标准、项目编排、证据与门禁之间的连接。下列状态必须以代码和验证记录更新，未完成项不能称为已交付。

| 工作 | 复用组件 | 必须验证的效果 | 当前状态 |
| --- | --- | --- | --- |
| 通用本地项目配置 | Pydantic、现有冻结输入与执行器 | 不依赖考核项目文档名；跨项目计划、执行、完整性与排除范围 | 配置与冻结已验证；三个异构成熟项目未达标 |
| 业务测试生成与覆盖 | pytest、Playwright、Schemathesis | 真实中文模型生成接口及页面路径；独立依据、持久状态和错误对照 | API/页面联合执行正负对照通过；新场景模型调用 504，未验证成功 |
| 持久任务与运行控制 | Huey、SQLite | 排队持久化、取消、重启后终态、中断不重放模型写请求 | 单 worker 已实测；旧 native 配方执行中取消与分布式执行未实现 |
| 缺陷历史与复验 | DefectDojo OSS API | 同问题多次出现、复核、工单关联边界、修复后原路径复验 | 同范围重复/关闭/重现已实测；跨工具身份、通用复核和工单未完成 |
| 结果调查与趋势 | ReportPortal OSS、Playwright Trace Viewer | 历史分类和聚类可用；步骤及现场证据能读懂 | Trace Viewer 已实测；ReportPortal 分析器、聚类未接入 |
| 持续交付门禁 | OPA、Git 平台检查协议 | 明确提交身份和冻结标准；CI 失败与未知不能放行 | GMAH PR #1 实跑拒绝、状态回读；main 必需检查未配置 |
| 扫描组合认证 | 现有工具及成熟语言原生工具 | 工具版本、规则、正负样例及真实项目结果 | 待扩充 |
| 安全及非功能深度 | ZAP、k6、Docker 隔离环境 | 认证权限负例、负载目标、故障和恢复读回 | 待扩充 |
| 权限与证据治理 | 成熟身份协议和存储组件 | 权限、凭据引用、操作审计及证据完整性 | 待实现 |

现有 110lab-assessment 验收与历史记录继续按原范围读取。商业设备池、托管人力和无对应本地环境的项目需明确环境依赖；不得把目录、报告解析或模拟服务验证写成真实能力认证。真实邮箱按此前决定排除。

开源选择依据：Huey 的 SqliteHuey 提供持久队列，运行中的任务在消费者意外退出时不能保证自动恢复，平台必须保留任务归属并将不确定执行标为中断，不能盲目重放模型调用。参见 [Huey 消费者](https://huey.readthedocs.io/en/stable/consumer.html)。现有 pytest、Playwright、Schemathesis、OPA 继续承担实际执行和门禁，不另写测试引擎。

具体结果、复现入口与未完成范围见 [D025 实现与验证](实现与验证.md)。
