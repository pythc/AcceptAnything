## 检查范围与结论

- 未知模型调用：新授权单独保存，绑定旧请求 ID 和原回执摘要；只允许明确授权的 upstream_unknown 继续新调用；排他锁与模型调用共用。旧回执不改成失败、取消或成功；将来的其他未知请求不自动放行。六项回归覆盖授权和回执变化。
- 业务执行：回调方法、无返回值、异步返回、thenable 按需等待均为通用协议。只把调用输入和观察路径送入被测进程，预期和比较留在宿主。回调异常、对象不可观察、清理异常不能作为产品缺陷；错误预期仍失败。
- Python 导入：src/平铺与命名空间段共用加载器；模块解析前后核对冻结文件路径，拒绝同名异源缓存。严格校验暴露的平台测试夹具污染已修复，未修改目标项目。
- 文档与生成：计划内短文档 ID 及合法枚举减少引用编号误写，原文定位和摘要仍严格核对；不猜测不存在的引用。Babel 只核对可解析引用中的显式回调动作/字面量/无返回值语义，不代表完整语义等价证明。配置读回校验是局部语法约束，不证明架构性质。
- JSON 比较：保留原 JSON 值，支持文本或结构化输入；成熟类型比较器区分布尔/数字，保留大整数。未把原预期改成实际输出。新增正确/错误预期与类型对照回归。
- CLI 观察：第十二版协议验证固定回执结构。输出需明确 /stdout 或 /stderr，退出码需 /exit_code；空路径只能比较完整回执。设计阶段按用例拒绝错误接线，运行防御记 error；不静默补路径。旧协议保持原边界。
- 异常隔离：每条用例独立捕获普通 Exception 并保存 traceback 与已有实际回执，后续独立用例继续；取消在循环外层检查，BaseException 不被吞掉。文件持久化失败仍可能导致整个任务 error，不能宣称任何基础设施失败都可恢复。
- 版本与证据：修复版先完成回归并冻结执行器摘要，再执行实仓任务；执行期间不编辑执行器。旧运行不重写，诊断回放与真实新模型完整运行单独记录。原始报告和原响应保留。
