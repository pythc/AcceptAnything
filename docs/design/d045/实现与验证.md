# D045 Agent 工具实现与验证

2026 年 11 月 5 日。本批为当前本机验收服务新增正式 MCP stdio 工具入口。

## 契约

使用官方 MCP Python SDK 1.30.0，独立依赖锁 requirements-agent.lock.txt。12 个工具具有独立的输入和输出 Schema，输入拒绝未声明字段；错误同时返回结构化 error 与 MCP isError。可执行输入只有服务已支持的操作，不接受任意宿主命令。

四个写工具为 prepare、start、cancel、review。默认只读，需显式 --allow-writes 委托写权限。prepare 的本地路径和 start 对应的本地来源均需通过当前 --allow-root 检查。start 只能使用本工具持久日志中准备的方案、相同后端身份和精确摘要。模型用例设计发生在 start 后，不把 prepare 说成模型已设计完成。

写操作先提交 SQLite 声明再调用后端。同一 request_id 重放返回已保存回执，参数变化拒绝。并发只有一个请求能派发。崩溃或失联留下未知，不自动重试；提供 operation 查询原始回执。此机制为至多一次派发，不承诺后端与工具日志之间存在跨进程原子事务。

## 查询

目录的状态与当前证据核验分开。status 重新读取结果契约。items 支持 requirements、observations、findings、checks、artifacts；所有发现分类均可遍历。游标绑定运行、集合和数据摘要，集合改变返回 stale_cursor。

evidence 绑定 run_id、artifact_id、expected_sha256，按字节返回 base64 片段、下一偏移及文件总长度。可连续读完整文件，页大小不限制仓库和总文件大小。后端核验原件归属及摘要；调用方重组后可再次核对完整摘要。

新增只读复核历史接口。链中的更正和原始意见均可读，保留每条事件的修订关系与原件核验结果。链分叉、断裂或事件内容被改写时拒绝将其视为完整历史。

## 实际验证

最终定向回归共 228 项通过，涉及 MCP 工具、追加复核、可扩展读取、结果契约、任务恢复、历史索引与连接。存在一条原有 Starlette TestClient 弃用提示。记录见 tests.log。

协议测试使用官方 SDK 执行 initialize、tools/list、tools/call，核对 12 项工具及错误输出结构。隔离目录中的真实 HTTP 业务入口测试完成 prepare、重复 start、cancel 和 events；确认仅创建一项任务，准备过程中未导入目标模块，目标文件字节不变。测试没有启动 worker 或模型。

真实 Fastify 历史运行的只读 stdio 验证逐页读取 37 条需求、90 条观察、12 条发现、19 项检查和 404 项原件元数据。按分块重组 219,700 字节原件并核对 SHA-256。该轮当前门禁仍为 inconclusive。此测试验证协议和数据可读性，不是一次新的模型业务验收。

安装了独立 .venv-agent 环境，本机只读客户端配置在 var/agent-tools/mcp.local.json，通用示例在 agent_tools/mcp.example.json。MCP 客户端尚需加载该配置，工具不会自动修改客户端的全局设置。本机 HTTP 服务继续监听 18890，验证用的临时 18893 已关闭。

## 当前边界

只支持本机单用户 stdio；没有远程 OAuth、多租户或项目级读取授权。allow-root 限制准备与启动，不对历史目录建立企业读取权限。日志丢失或写调用结果未知时须先对账，不能通过换日志或换 UUID 自动重放。客户端使用规程见 docs/Agent工具接入.md。
