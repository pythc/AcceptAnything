## 输入、标准与方案

1. 本地仓库继续使用 D019 的文件白名单、容量限制和只读快照。支持需求文本、API 契约及用户补充的独立业务规则。
2. 标准记录标题、处理优先级、原文引用、来源文档、引用行号与摘要。引用必须逐字存在于输入依据，不能从目标实现反推期望。
3. 每条必验标准必须关联场景。未知预期标为 `unresolved`，阻止启动；真实邮箱等明确排除的范围记录原因，不生成用例、不计入未完成数。
4. 场景使用数据表、笛卡尔积矩阵或数值边界展开。记录正常、边界、异常、权限、状态与持久化等实际设计角度，不用固定百分比宣称需求全覆盖。单计划最多200个生成用例。
5. 方案、来源文档、源文件与权限位、生成文件、执行器代码、工具链摘要共同冻结。启动和执行时重新核验；变化后重新生成方案，不能沿用旧确认。

原文匹配只能证明出处，不能证明模型或设计者理解正确。当前仍需核对标准含义、边界数据与预期。

## 执行框架与复用组件

| 功能 | 复用组件 | 本项目负责的部分 |
|---|---|---|
| 方案契约 | Pydantic、JSON Schema | 严格结构、引用校验、未决项阻断、变更绑定 |
| 模块/接口用例 | pytest、jsonschema、JUnit | 新测试函数、输入/断言驱动、多步捕获与读回、步骤实际值 |
| 页面流程 | Playwright | 新页面用例、导航/输入/点击/勾选/页面断言、失败截图与 trace |
| API 属性验证 | Schemathesis | 冻结独立 OpenAPI 3 JSON、合法/非法及边界请求、核对全部接口操作 |
| 通用质量检查 | 已接入的固定扫描器配方 | 按技术栈选择适用检查，保留各自原始结果 |
| 汇总与放行 | 现有格式归一化、OPA | 必验用例名单、数量、结果与退出码一致性、未知结果阻断 |

生成的 pytest/Playwright 文件不来自被测仓库已有测试。测试输入与期望存入冻结的方案，可信驱动读取该方案运行；生成文件、方案和驱动一并作为证据。OpenAPI 对每个契约接口操作核对实际报告名称，漏跑或重复报告均不能通过。外部引用被拒绝；Path Item 引用当前要求先展开。

目标代码运行在一次性 Docker 容器，源文件只读挂载，取消额外权限，限制 CPU、内存与进程数。独立测试驱动不导入目标模块；通过只返回实际值的模块桥或目标 HTTP 接口交互。目标不挂载断言、报告目录或宿主凭据。

Docker Desktop 的内部网络不能直接发布端口，本地实现采用独立的固定目标 TCP 转发容器；仅绑定127.0.0.1临时端口，转发至该次目标端口。转发容器没有源代码、断言或输出挂载；目标容器保留内部网络。浏览器请求限制为目标来源，WebSocket关闭。所有本批容器和网络按执行标识清理，不操作其他项目网络。此为本地执行隔离，未宣称具备对容器逃逸的生产级安全保证。

## 结果与溯源

每个普通生成用例记录来源、参数、步骤、预期、实际值、状态和耗时。通过、失败、错误、跳过、等待和批次执行中分别表达；不以退出码0代替断言结果。原生报告缺失、用例遗漏、步骤缺失、执行错误或结果不一致均不能通过。

归档复核同时核验方案、生成代码/驱动清单、原生报告和步骤证据。摘要可发现意外变化，但不是数字签名，不能声称来源已被外部可信认证。

原“用例登记”保留用于现有配方。新模式的“分析依据与设计用例”发生在执行前，显示实际生成耗时和生成结果。扫描器命中继续保留候选发现和待复核状态，不冒充已证实攻击。

## 当前边界

- 支持任意本地路径作为接入入口，不等于任意技术栈无需配置即可启动。生成器当前支持Node/TypeScript、Python模块和直接脚本服务；不自动安装未知依赖，不执行任意宿主命令，多服务项目须另做环境适配。
- 生成器暂不生成性能/恢复场景；提交这两类场景会明确拒绝。现有k6/恢复配方仍可使用，不能以普通接口请求冒充压力或恢复验证。
- 需求文档没有说明的行为不能猜测；已录入标准的覆盖不能代表整份文档所有隐含需求都被自动识别。
- 模型适配器只通过模拟HTTP响应验证；没有真实模型连接或效果评价。当前前端显示“模型未配置”，不会悄悄伪造模型方案。
- 复杂登录、真实邮箱、第三方付费服务、生产验收、WorkSwarm编排不在本批新能力完成声明内。
