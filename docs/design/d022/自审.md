# D022 · 代码自审

检查入口、后台编排、模型传输、方案编译、父子收据、门禁、历史投影与前端计时。

- 新建请求只接受本地路径及已确认计划摘要，不接受宿主命令。同源、本地Host、严格请求模型保留。
- 原始仓库只读冻结；冻结前后摘要核对，子任务逐文件与父快照比较；配方与编排变化使未启动计划失效。
- 未知仓库没有可验证环境时阻止完整验收，不替换成静态扫描成功。
- GPT-6 Thinking High实际响应必须为extended/stop；超时保留未知，精确网关终态才能解锁，无隐式重试或Pro回退。
- 决策表变量和预期类型由Pydantic/JSON Schema核对。原始模型预期保留，反例回归确保不会按实现修正答案。
- 所有模型批次须有实际用例执行收据；子报告失败影响父门禁。模型失败或环境缺项不能被排除。
- 缺失阶段、未完成检查、子记录篡改和跨验收取证均有反向回归。
- 历史原件不重写；统一视图标记所选范围及未完成，不补造计时。
- 最终门禁与各子门禁分别标识，避免把子检查通过解释为完整验收通过。

局限：本机摘要不是第三方签名；完整环境配方当前针对已登记的assessment；本地5VU/20秒负载与数据库/文件恢复不代表生产容量或跨地域灾备。模型生成测试当前仅覆盖五项明确模块业务标准，其他层使用已审核的现有配方。

结束后收紧逐批High元数据校验，五项标准须一一对应独立草稿且各有执行凭据。实际封存报告通过该复核。生成断言详情只读取已校验trace，缺trace不猜输入或实际值；新增回归核对证据归属和非产品缺陷声明。
